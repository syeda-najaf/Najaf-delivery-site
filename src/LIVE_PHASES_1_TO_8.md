# Najaf Delivery: Live Food-Delivery Foundation

This package prepares the project for phases 1 to 8:

1. Backend + MongoDB + authentication foundation
2. Real order creation API
3. Restaurant order/status workflow API
4. Delivery-partner assignment + dashboard API foundation
5. Browser GPS location sharing
6. Socket.IO customer live tracking
7. Order history/status events
8. Production deployment configuration foundation

Important:
- This is a real backend foundation, not fake rider animation.
- MongoDB Atlas credentials are required before the server can run.
- Online card payments still require a payment provider such as Razorpay/Stripe and merchant credentials.
- Maps use the existing Leaflet approach. Do NOT install react-leaflet in this React 17 project.
- The existing frontend pages still need to be wired to these APIs. The helper files are included for that integration.
